grok-4.5 API 在国内怎么调用？

迁移成本几乎为零，改 base_url 和 api_key 两个值就行，其余业务代码一行不用动。

  1. 确认账号分组：先在平台面板确认当前账号所属分组及对应倍率，实际结算价格由基准价乘以该倍率得到。
  2. 核对模型名称：在可用模型列表中确认请求使用的模型名为 grok-4.5。
  3. 获取接入信息：从平台面板获取当前账号对应的请求地址、鉴权凭证和请求格式，不要将示例中的环境变量占位值用于生产环境。
  4. 发起最小请求：先使用短文本请求验证模型可用性、响应格式和实际计费记录。
  5. 核对账单与延迟：将请求 token 用量、分组倍率和账单记录交叉核对；首字延迟等性能数据需按自身网络环境实测。

完整代码示例

import json
import os
from urllib.request import Request, urlopen

api_url = os.environ["API_URL"]  # 替换为面板提供的实际请求地址
api_key = os.environ["API_KEY"]  # 替换为面板提供的实际鉴权凭证

payload = {
    "model": "grok-4.5",
    "messages": [
        {"role": "user", "content": "请用一句话说明这段请求用于连通性测试。"}
    ]
}

request = Request(
    api_url,
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Content-Type": "application/json",
        "Authorization": f"Bearer {api_key}"
    },
    method="POST"
)

with urlopen(request, timeout=60) as response:
    print(response.read().decode("utf-8"))
